# Evidence

`backtest.json` is generated by `npm run benchmark`. It contains dataset shape and hash, metric definitions, baseline and challenger results, a paired user-level bootstrap interval, runtime metadata, and the scope limitation attached to the result.

`loadtest.json` is generated by `npm run loadtest`. It contains 20,000 in-process request timings under a deterministic request mix. This isolates RankForge ranking-path cost from network and container overhead; it is not a distributed production load claim.

Both files are checked by `npm run validate:evidence`. Headline values in the application and README must be updated from these artifacts, never from manual estimates.
